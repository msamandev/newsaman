## ✨ Key Features

- **Interactive 3D Hanging ID Card**: Realistic physics-based dangling ID card showcasing developer credentials and profile badge.
- **Bento Grid Selected Works**: Responsive 12-column Bento Grid displaying real production projects with direct live demo links.
- **Interactive Career Timeline**: Visual milestone journey detailing engineering, evaluation, and educational roles.
- **Lenis Smooth Scrolling**: Ultra-smooth page momentum and fluid scroll navigation.
- **Scroll-Aware Header & Floating Dock**: Dynamic adaptive top navigation and macOS-style floating bottom dock.
- **Direct WhatsApp Contact Integration**: Form inputs that automatically parse and format inquiries straight into WhatsApp chat.
- **Dark & Light Theme**: Seamless theme switcher powered by modern CSS custom properties and View Transitions.
- **SEO & Open Graph Ready**: Complete social media sharing cards for WhatsApp, LinkedIn, and Twitter previews.

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.x or 20.x recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/msamandev/newsaman.git
   cd newsaman
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:8080](http://localhost:8080) in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
   Outputs production-ready static assets to the `dist/` directory.

5. **Linting check**:
   ```bash
   npm run lint
   ```
